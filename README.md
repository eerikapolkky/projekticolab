In the Simple Audio project, we implemented and trained a convolutional neural network for voice command recognition using the provided simple_audio_project template. The objective of the project was to understand the internal structure of a convolutional neural network by implementing all its main components manually and verifying that the custom implementations produce identical results to the ready-made model.

First, the convolutional neural network was trained using the provided project structure, achieving a recognition accuracy of over 80% for the audio commands. After confirming the baseline performance, I gradually replaced the pre-built neural network components with my own implementations according to Figure 1 and validated the results after each step.

We implemented custom versions of all required functions shown in Figure 1, including convolution1(), convolution2(), maxPooling(), flatten(), dense1(), and dense2(). Each function was written from scratch without using high-level library implementations. The correctness of each function was verified by comparing intermediate outputs and final classification results with those produced by the original model.

The convolution1() and convolution2() functions were implemented by manually handling filter operations, including sliding the kernels over the input data, computing element-wise multiplications, and summing the results. The maxPooling() function was implemented to reduce the spatial dimensions while preserving the most significant features. The flatten() and dense1() functions were used to convert the convolutional output into a vector representation and perform the first fully connected layer. Finally, the dense2() function produced the output layer responsible for classifying the audio commands.

As a final result, the complete neural network consisting entirely of self-implemented functions was able to classify audio commands from input audio files with the same outputs as the original ready-made model. This project significantly improved my understanding of convolutional neural networks, audio data processing, and the mathematical operations underlying deep learning models.
